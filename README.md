## About HatodNow

**HatodNow** is the front-end for a conceptual delivery service based in Davao City. This project is a static landing page designed to be modern, engaging, and visually striking, reflecting the speed and efficiency of the service it represents. It features a dark, tech-inspired aesthetic with a vibrant orange accent color.

<br>

> [!NOTE]
> This is a front-end demonstration and does not have a functional back-end. The live tracking and business dashboard are for illustrative purposes.

## Features

This landing page is packed with modern UI/UX features to create a memorable user experience:

*   **Cinematic Splash Screen:** An animated, full-screen intro that stylishly reveals the brand.
*   **Parallax Hero Section:** A multi-layered hero section with elements that move at different speeds on scroll, creating a sense of depth.
*   **Interactive Delivery Tracking Card:** A visual simulation of a live delivery, complete with a moving rider pin on a map.
*   **Custom Animated Cursor:** A two-part cursor that provides visual feedback on hover and enhances the tech feel.
*   **Animated UI Cards:** Sleek, floating cards for features and business statistics that animate on hover and scroll.
*   **Marquee Ticker:** A continuously scrolling banner of "trusted by" partners.
*   **Modern & Themed Design:** The entire UI is built using CSS variables, making it easy to theme. The design is dark, clean, and professional.
*   **Fully Responsive:** Looks great on all devices, from mobile phones to desktop screens.

---

## Built With

The project is built with pure, vanilla web technologies, with no external frameworks.

*   **HTML5:** For the structure and content.
*   **CSS3:** For all styling, animations, and responsiveness.
    *   **CSS Variables:** Used extensively for theming and maintaining a consistent design system (colors, shadows, etc.).
    *   **CSS Animations & Keyframes:** Powers all the dynamic effects, from the splash screen to the parallax backgrounds.
*   **JavaScript:** For DOM manipulation and interactive features like the custom cursor and scroll-based animations.
*   **Google Fonts:** Utilizes the `Barlow` and `Barlow Condensed` font families for its distinct typography.
